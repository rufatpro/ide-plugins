## Сфера применения

Расширение рассчитано на связку **Cursor + внешняя IDE**, когда в Cursor вы в основном работаете с **AI-чатом** (Composer, Agent, ссылки на файлы в ответах), а **редактирование кода** удобнее в другой среде — PyCharm, IntelliJ IDEA, WebStorm и т.п.

Типичные задачи:

- отладка и навигация по проекту во внешней IDE с привычными инструментами;
- правка кода в PyCharm, пока агент в Cursor предлагает изменения и ссылается на файлы;
- опциональный журнал кликов по ссылкам из чата («куда отправил агент»).

Расширение **не заменяет** Cursor и **не синхронизирует** правки между редакторами.

## Пример сценария

**Основной редактор — PyCharm**, **AI-чат — в Cursor.**

1. В `settings.json` задаёте `redirectFileExtensions` (например `py`) и при необходимости `externalIdePath` к `pycharm64.exe`.
2. В чате Cursor агент отвечает со ссылкой на `src/service.py:42` — вы кликаете по ссылке.
3. Cursor на мгновение открывает **новую** вкладку; расширение запускает PyCharm на нужной строке и (по умолчанию) закрывает вкладку в Cursor.
4. Если задан `logPath`, в файл пишутся события открытия/закрытия.

## Когда срабатывает редирект

Редирект привязан к появлению **новой вкладки** редактора в Cursor (`onDidChangeTabs` → `opened`), а не к простому переключению активного файла.

| Ситуация | Редирект во внешнюю IDE? |
|----------|---------------------------|
| По ссылке из чата открывается файл, у которого **ещё нет вкладки** в Cursor | **Да** — появляется новая вкладка, затем открывается PyCharm (и т.д.) |
| Ссылка из чата ведёт на файл, который **уже открыт** во вкладке (Cursor только переключает фокус) | **Нет** — новой вкладки нет, расширение не считает это «открытием из чата» |
| Клик по **уже существующей** вкладке на панели сверху | **Нет** — меняется только активная вкладка |
| Файл открыт из Explorer / палитры команд (новая вкладка) | **Да** — это тоже новая вкладка, тот же механизм, что у ссылки из чата |

На практике:

- первый клик по пути из чата обычно даёт редирект; повторные клики по той же ссылке при уже открытой вкладке — **часто нет**;
- чтобы снова перенаправить файл, закройте его вкладку в Cursor и снова кликните ссылку в чате (или откройте ссылку, пока вкладки ещё нет).

События лога (`file.openedInCursor` и др.) пишутся для тех же расширений, только если задан непустой `logPath`.

## Установка

```bat
cd plugins\vscode\cursor-ai-chat-click-redirect
build.bat
```

В Cursor / VS Code: **F1** → `Extensions: Install from VSIX` → `build\cursor-ai-chat-click-redirect-0.6.6.vsix`.

Перезагрузите окно (**Developer: Reload Window**).

## Быстрая настройка

```json
{
  "cursorAiChatClickRedirect.redirectFileExtensions": "py,js,md",
  "cursorAiChatClickRedirect.externalIdePath": "C:\\Program Files\\JetBrains\\PyCharm 2025.1.2\\bin\\pycharm64.exe",
  "cursorAiChatClickRedirect.keepTabInCursorAfterRedirect": false,
  "cursorAiChatClickRedirect.logPath": "c:\\tmp\\ai_chat_click.log"
}
```

| Настройка | По умолчанию | Описание |
|----------|--------------|----------|
| `redirectFileExtensions` | `""` | Расширения через запятую без точки (`py,js,md`). Пусто — редирект **выкл.** |
| `keepTabInCursorAfterRedirect` | `false` | Оставить вкладку в Cursor после открытия во внешней IDE. |
| `logPath` | `""` | Путь к лог-файлу. Пусто — **логирование выкл.** |
| `externalIdePath` | `""` | Путь к IDE. Пусто — автопоиск JetBrains в Windows. |
| `externalIdeArgs` | `["--line","{line}","{file}"]` | Аргументы запуска; `{file}`, `{line}` (с 1). |

В интерфейсе настроек `redirectFileExtensions` отображается первой.

## Статус-бар

- `py,js → OS` — редирект включён (клик — изменить список).
- `redirect off` — редирект выключен (клик — задать расширения).

## Команды

| Команда | Действие |
|---------|----------|
| **Задать расширения для редиректа в ОС** | Список через запятую или пусто |
| **Открыть лог кликов AI Chat** | Открыть лог (нужен `logPath`) |
| **Очистить лог кликов AI Chat** | Очистить лог (нужен `logPath`) |
| **Тестовая запись в лог AI Chat** | Проверка лога (нужен `logPath`) |

## События в логе

Запись только при непустом `logPath`:

| Событие | Когда |
|---------|--------|
| `file.openedInCursor` | Файл с нужным расширением открыт во вкладке Cursor |
| `file.closedInCursor` | Вкладка закрыта |
| `file.openedInExternalApp` | Файл открыт во внешней IDE |
